# Regras de negocio

Este documento concentrara as regras de negocio do Athletix. As primeiras definicoes serao registradas por modulo conforme as funcionalidades forem implementadas.

## Principios iniciais

- Cada dado pertence a uma atletica.
- Usuarios so podem acessar recursos permitidos pelo seu cargo.
- O backend concentra validacoes, regras e calculos.
- O frontend apenas apresenta dados e solicita operacoes a API.
